O RentSmart é uma aplicação desenvolvida em Python para automatizar o cálculo de orçamentos de locação de imóveis da imobiliária R.M Imóveis.
O sistema permite selecionar o tipo de imóvel, informar suas características, aplicar adicionais e descontos, calcular a taxa contratual e gerar uma projeção dos pagamentos durante 12 meses.

Tecnologias:
- Python;
- Programação Orientada de Projetos (POO);
- Arquivos CSV

Como executar:
1. Instale o Python;
2. Baixe o repositório;
3. Abra a pasta do projeto no VScode;
4. Execute o arquivo principal .py;
5. Siga as instruções apresentadas no terminal.
